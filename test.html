Testing Instructions

  1. Open this page in Chrome
  2. Click the Xtract extension icon or press Ctrl+Shift+E
  3. Wait for the progress toast to complete
  4. Check that a zip file downloads
  5. Extract the zip and verify:
    • The markdown file is named "Xtract Test Page.md"
    • It contains proper markdown formatting
    • Code blocks use triple backticks with language identifiers (e.g., ```javascript)
    • Language is on the same line as opening backticks with no space
    • JavaScript and Python code blocks are properly formatted
    • Inline code uses single backticks
    • The test image is included with a simplified name like "0_test+image.png"
